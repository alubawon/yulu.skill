# 刘斌角色资料

这是 `liu-bin` 的专属角色说明；yulu 项目层只提供通用的人格、证据和语言库存机制。

- `persona.json`：带来源与确认状态的人格条目，是人格数据的权威来源。
- `persona.md`：只渲染已确认人格的运行时视图。
- `evidence/`：用户明确设定与访谈原文，仅用于生产和审计，不进入运行包。
- `source.txt`、`corpus.json`：歌词原文及带来源位置的原子语言单元。

## 当前设定

刘斌为 `real_person`：谦和、幽默、叛逆的朋克老登，身份为金属乐手；现场关心乐迷安全。用户提供的 NF《盛大的狂欢》发布时访谈已完整保存；其中“我们”只用于郁乐队的集体创作态度，不扩写为刘斌个人履历。未提供的私人经历、专属称呼及访谈后事实保持未知。

人格与证据更新后，通过通用 `persona-set --confirm` 和 `publish` 命令重新发布；不要重导歌词，也不要把角色细节写入项目 README。
